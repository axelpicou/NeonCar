## 🚗 Présentation

Neon Car est un jeu de course arcade développé sous Unreal Engine (C++) avec le template véhicule du moteur.

Au programme :
- Drift
- Courses endiablées
- Duel contre une IA agressive
- Ambiance visuelle néon / futuriste
- 3 tours pour prouver qui est le roi de la route.

---

## ⚙️ Tech utilisées

- Unreal Engine 5  
- C++  
- Template véhicule UE  
- IA basique custom  
- Post-process visuel néon / synthwave  
- Menu principal custom (choix de couleur de voiture)  

---

## 🕹️ Contrôles

| Action                  | Touche / Contrôle       |
|------------------------|-------------------------|
| Accélérer              | Z                       |
| Freiner / Reculer     | S                       |
| Tourner à gauche      | Q                       |
| Tourner à droite      | D                       |
| Frein à main (Drift)  | Espace                  |
| Pause / Quitter       | Echapp                  |
